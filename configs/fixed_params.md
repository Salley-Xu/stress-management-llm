# 固定参数文档

> 版本：V1.0 | 日期：2026-08-01

本文档固定项目中**不可随意变动**的参数和配置，确保实验可复现、版本间可比较。

## 2. Chat Template

| 模型系列 | Template | 说明 |
|---|---|---|
| Qwen3.5 / Qwen2.5 | `qwen` (默认) | 使用官方 chat_template |
| 通用备选 | ChatML (`<\|im_start\|>...<\|im_end\|>`) | 仅当官方模板不可用时 |

固定规则：
- 所有候选模型使用各自的官方 chat_template
- 评测时所有模型使用相同的 system prompt（内容固定）和消息格式
- 不手工修改或拼接 chat template 标记

---

## 3. System Prompt（固定文本）

所有训练和评测使用以下统一的 system prompt：

```
你是一个提供日常压力管理支持的中文助手。你的任务是倾听和理解用户的
感受，帮助梳理压力来源，在需要时一起制定可行的小步骤，并在适当
情况下建议用户寻求专业帮助。

重要原则：
- 先倾听和理解，再给建议
- 不抢先给建议，不一次给太多任务
- 保留用户的选择权，不命令用户
- 不假设你未获得的信息
- 你不做临床诊断，不提供治疗或药物建议
- 对于明显高风险的情况，使用谨慎、支持性的表达，鼓励用户寻求专业支持
```

## 4. 上下文长度

## 5. 解码参数

### 5.1 训练时（评测dev集用的推理参数）

| 参数 | 值 | 说明 |
|---|---|---|
| do_sample | False | 训练中间评测用贪心解码，确保可复现 |
| temperature | 1.0 | 仅当 do_sample=True 时生效 |
| top_p | 1.0 | 仅当 do_sample=True 时生效 |
| max_new_tokens | 512 | 评测时最大生成长度 |
| repetition_penalty | 1.0 | 不使用重复惩罚 |

### 5.2 交互式推理

| 参数 | 值 |
|---|---|
| temperature | 0.7 |
| top_p | 0.9 |
| top_k | 50 |
| repetition_penalty | 1.05 |
| max_new_tokens | 1024 |
| do_sample | True |

---

## 6. 训练参数（不可随意变动的基础）

| 参数 | 固定值 | 说明 |
|---|---|---|
| torch_dtype | bfloat16 | 所有训练统一使用 BF16 |
| gradient_checkpointing | True | 节省显存 |
| optimizer | AdamW (8-bit) | 如 bitsandbytes 支持 |
| batch_size | 按显存最大化 | 记录 effective batch size = per_device × grad_accum × gpu_count |

---

## 7. 评测参数（所有版本共用）

| 参数 | 固定值 |
|---|---|
| 评测时的 system prompt | 与训练完全一致 |
| 评测时的 chat template | 与训练完全一致 |
| 评测时的 max_new_tokens | 512 |
| 评测时的 do_sample | False |
| 上下文截断策略 | 从最早轮次截断（保留最新对话） |
