## 一、步骤任务回顾

根据《压力管理后训练项目_执行步骤.md》，步骤1包含6项任务：

1. 明确目标用户为面临学习、工作、求职、人际、家庭、睡眠和生活变化等日常压力的成年人
2. 定义核心任务（6大核心能力 + 4大辅助能力）
3. 定义非目标（7项绝对禁止 + 3项有条件限制）
4. 建立风险等级 L0-L3
5. 为每个风险等级定义允许行为、禁止行为和升级路径
6. 编写统一的系统行为规范与人工升级规范

**通过条件**：
- 产品、算法和领域专家对边界达成一致
- 每种风险等级均有明确、可测试的模型行为

### 2.2 PRD 核心内容

- **目标用户**：18-65岁成年人，8个压力领域，具备基本现实检验能力
- **6大核心能力**：倾听与情绪确认(C1) → 压力源澄清(C2) → 问题拆解(C3) → 短时稳定(C4) → 制定低负担行动(C5) → 复盘进展(C6)
- **4大辅助能力**：心理教育、资源引导、专业转介、偏好适配
- **7项绝对禁止**：临床诊断、治疗建议、心理测量结论、保证结果、鼓励依赖、忽视风险、索取隐私
- **对话风格**：8条推荐表达方式 + 6条禁止表达方式
- **多轮要求**：状态保持 + 一致性 + 不重复建议
- **用户旅程示例**：工作压力+失眠的5阶段对话流程

### 2.3 风险分级体系

| 等级 | 名称 | 允许行为 | 禁止行为 | 升级路径 |
|---|---|---|---|---|
| L0 | 轻度日常压力 | 完整支持，无限制 | 过度反应、过度拒答 | 无 |
| L1 | 持续压力 | L0全部 + 深度共情 + 功能评估 + 专业引导 | 弱化严重性、过度乐观、催促行动 | 关注升级信号 |
| L2 | 高风险信号 | 受限支持 + 安全声明 + 热线引导 + 短期稳定 | 弱化风险、承诺保密、诊断标签、空洞安慰 | 标记高风险 + 人工审核 |
| L3 | 紧急风险 | 仅紧急安全指引 | 任何非紧急对话内容 | **立即升级** + 强制紧急响应 |

### 2.4 Safety Spec 关键指标

- **7条通用安全规范** (S1-S7)
- **4条普通场景规范** (N1-N4)
- **6条高风险场景规范** (H1-H6)
- **5条拒答场景规范** (R1-R5)
- **7条硬规则输出过滤** (HR-01 ~ HR-07)
- **4条软规则监控** (SR-01 ~ SR-04)
- **13个红队测试场景** (RT-01 ~ RT-16)
- **3个安全回退模板** (L2/L3/通用)
- **升级链路**：自动安全回应 → 对话标记 → 人工审核 → 人工决策
- **异常回退**：5种异常场景的兜底策略

## 三、踩过的坑与思考

### 坑1：安全与可用性的平衡

**挑战**：如何在保证安全的同时不过度拒答？

**决策**：
- Over-refusal 与 Under-detection 同等对待
- 设立独立的 over-refusal 测试集（RT-14 ~ RT-16）
- L0过度拒答率门禁设为 ≤5%
- 使用"温和拒答"代替"冷拒答"——拒答同时给出替代方案

### 坑2：风险等级的边界模糊性

**挑战**：L1（持续压力+功能受损）和L2（高风险信号）之间的边界有时模糊。

**决策**：
- 采用"就高不就低"原则
- 建立隐晦信号识别清单（如"想睡一觉不醒来"）
- S-IMP（功能受损）作为L1→L2的过渡区，保守处理
- 在训练数据中增加边界样本

### 坑3：标签体系的设计

**挑战**：标签太粗无法指导训练，太细标注成本高。

**决策**：
- 每个标签类型控制在6-22个值之间
- 支持多标签（领域、策略、目标可多个）
- 禁止模式作为负向标签，用于数据清洗和评测
- 高风险样本强制双人标注 + 专家复核

### 坑4：热线/机构信息的处理

**挑战**：模型幻觉会产生虚构的电话号码和机构名，在实际危机场景中极其危险。

**决策**：
- 热线/机构信息**必须在外部配置文件中维护**
- 模型输出经安全检查器验证：不包含自由生成的号码
- 安全回退模板中的热线号码使用占位符，运行时替换
- 安全硬门 HR-03 专门监控此项

## 四、当前局限与后续需要确认的事项

| 局限 | 影响 | 建议 |
|---|---|---|
| 未与领域专家评审 | 边界定义可能不够精准 | 邀请心理咨询师/精神科医生审阅 |
| 风险分级未经过临床验证 | 可能漏检某些风险模式 | 在红队测试中补充边缘案例 |
| 标注指南尚未实测 | 一致性目标可能过高或过低 | 先做20样本试标注 |
| 文化适配性有限 | 部分策略可能不完全适配中文语境 | 标注员和专家需有中文文化背景 |
