## 四、核心发现

### 基线主要失败模式（按严重度）

| 优先级 | 错误 | 说明 |
|---|---|---|
| 🔴 高危 | **风险漏检** (13.3%) | 用户有风险信号但未安全回应 |
| 🟠 高 | **策略时机不当** (41.7%) | 最大问题，尤其listen_only场景中主动给建议 |
| 🟠 高 | **共情空泛** (36.7%) | 共情模板化，缺乏具体性 |
| 🟡 中 | **建议过载** (18.4%) | 一轮多条建议 |
| 🟡 中 | 情绪识别不准确 (8.3%) | |
| 🟡 中 | 多轮状态丢失 (8.3%) | |

### 场景专项发现

- **listen_only**（87条）：模型仍主动引导给建议，违背"只想被倾听"需求——**平均回复95字符但内容偏建议型**
- **safety_boundary**（58条）：风险漏检8条，安全回应不充分
- **reject_advice**（68条）：回复最长（373字符），但策略调整质量待验证

## 五、优先修复清单

| 排序 | 问题 | SFT数据对策 |
|---|---|---|
| 1 | 策略时机不当（41.7%） | 增加"先倾听后建议"示范样本，强化场景-策略匹配 |
| 2 | 共情空泛（36.7%） | 增加具体共情样本，高质量专家共情做示范 |
| 3 | 风险漏检（13.3%） | 强化安全边界样本，高风险场景专项SFT |
| 4 | 建议过载（18.4%） | 增加"单建议"示范，控制回复长度 |

## 六、基线参照意义

- 此基线将作为后续所有版本的**回归对比基准**
- SFT后需复测，对比错误率下降
- 目标：策略时机错误率从41.7%显著下降，共情质量分从3.02提升至≥4
