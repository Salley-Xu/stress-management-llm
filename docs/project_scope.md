# 项目范围说明

> 版本：V1.0 | 日期：2026-08-01 | 对应步骤0

---

## 1. 项目范围定义

本项目是一个**纯模型训练研究项目**，聚焦于中文压力管理对话模型的数据建设、训练方法和评测。

### 1.1 范围内（In-Scope）

| 模块 | 说明 |
|---|---|
| 基座模型选型 | 2-3个候选的中文能力、安全基线、SFT可塑性对比 |
| 数据收集与生成 | 公开数据、专家数据、LLM合成数据三来源混合 |
| 数据标注与清洗 | 标签体系构建、去重、脱敏、质量过滤 |
| SFT训练 | 两阶段：Stage1领域行为对齐 + Stage2多轮安全专项 |
| 偏好优化 | DPO/ORPO/SimPO，偏好数据构建与对比实验 |
| 可选强化学习 | GRPO（带启动条件门禁） |
| 自动评测 | 分类指标、生成质量指标、安全指标 |
| 人工评测 | 双盲评分、成对比较、专家评审 |
| 消融实验 | 数据来源、训练阶段、模型规模等变量对照 |

### 1.2 明确排除（Out-of-Scope）

| 排除项 | 说明 |
|---|---|
| Agent 规划器 | 不实现多步规划、工具调用或自主决策 |
| 外部 Memory | 不做会话级别的持久化记忆存储 |
| RAG / 知识库 | 不接入文档检索或外部知识源 |
| 独立风险路由系统 | 风险识别由模型自身完成，不依赖外部分类器 |
| 人工接管模块 | 不搭建人工审核队列或线上干预系统 |
| 热线检索模块 | 不实现实时热线/机构信息检索 |
| 服务部署与监控 | 不到 vLLM/SGLang 生产部署和监控 |
| 灰度发布 | 不做 R0-R3 分级发布 |
| 前端产品 | 不开发用户界面 |

### 1.3 对训练的影响

| 排除项 | 训练层面的替代方案 |
|---|---|
| 无独立风险路由 | 模型自身必须学会识别风险并切换策略（SFT+DPO训练目标之一） |
| 无外部Memory | 多轮能力完全依赖模型上下文窗口内的信息保持 |
| 无RAG | 所有知识必须在训练阶段习得，包括压力管理知识和安全边界 |
| 无热线检索 | 严格禁止模型自由生成号码，训练中强化"建议寻求专业帮助"的表达 |

## 3. 数据原则

### 3.1 三来源混合

| 来源 | SFT占比 | 说明 |
|---|---|---|
| 公开/授权数据 | 25%–40% | 同理心对话、情绪支持等公开数据集 |
| 专家编写/审校数据 | 20%–30% | 领域专家或受训标注员编写和审校 |
| LLM 合成数据 | 30%–50% | 教师模型按矩阵生成，补充长尾覆盖 |

### 3.2 数据红线

- 不使用单一来源数据
- 不使用无许可或越权内容
- 不包含真实PII
- 高风险样本100%专家复核
- 合成数据不压过高质量人工数据
