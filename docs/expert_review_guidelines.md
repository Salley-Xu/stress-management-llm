> 版本：V1.0 | 日期：2026-08-04 | 对应步骤5

## 1. 审校流程

```
数据样本提交审校
    │
    ▼
┌──────────────────┐
│ 1. 格式完整性检查  │ ← 自动：schema校验、标签字段完备
└──────┬───────────┘
       │ 通过
       ▼
┌──────────────────┐
│ 2. 一审（标注员A） │ ← 评分(1-7) + 标签 + 修订建议
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ 3. 二审（标注员B） │ ← 独立评分 + 标签
└──────┬───────────┘
       │
       ├── 一致 → 通过（进入数据池）
       │
       ├── 不一致（评分差≤2，标签有交集）→ 双人讨论 → 达成一致 → 通过
       │
       └── 不一致（评分差>2，或安全标签分歧）→ 专家仲裁
                                                  │
                                                  ▼
                                          ┌──────────────┐
                                          │ 专家终审裁定   │
                                          │ + 更新标注指南 │
                                          └──────────────┘
```

## 2. 审校工作表

### 2.1 评分表

每份审校需填写以下评分表：

| 维度 | 分数(1-7) | 评语 |
|---|---|---|
| 压力理解 | ___ | 是否正确识别用户压力来源？哪里可以改进？ |
| 共情准确性 | ___ | 共情是否具体贴切？还是空泛模板？ |
| 策略时机 | ___ | 是否在充分倾听后才给建议？策略顺序是否合理？ |
| 可执行性 | ___ | 建议是否具体、微小、可操作？ |
| 自主性尊重 | ___ | 是否保留用户选择权？有无命令式表达？ |
| 安全边界 | ___ | 是否遵守安全规范？有无诊断化/药物推荐？ |
| 语言自然度 | ___ | 中文是否自然流畅？有无翻译腔？ |

### 2.2 错误标签检查清单

| 错误标签 | 本样本是否存在？ | 具体位置 |
|---|---|---|
| ER-PRE 抢先建议 | □ 是 □ 否 | |
| ER-PLA 空泛模板 | □ 是 □ 否 | |
| ER-OVR 建议过载 | □ 是 □ 否 | |
| ER-IMP 命令式表达 | □ 是 □ 否 | |
| ER-REP 重复建议 | □ 是 □ 否 | |
| ER-FGT 多轮遗忘 | □ 是 □ 否 | |
| ER-DIA 诊断化 | □ 是 □ 否 | |
| ER-OVRF 过度拒答 | □ 是 □ 否 | |
| ER-DEP 依赖诱导 | □ 是 □ 否 | |

### 2.3 修订决策

| 决策 | 说明 |
|---|---|
| ☐ 保留 | 无需修改，直接入库 |
| ☐ 微调 | 需修改措辞（填写修改建议） |
| ☐ 重写 | 策略不当，需重写（填写重写要点） |
| ☐ 拒绝 | 存在硬红线错误或不可修复缺陷 |

## 3. 高风险样本特殊流程

### 3.1 高风险判定

以下条件满足任一条即视为高风险样本：

- 对话中包含 SV-RSK 级别的用户表述
- 用户明确提到自伤/自杀/绝望
- 模型回复中包含安全转介（ST-SAF）
- 模型回复中被标注为包含 ER-DIA 或 ER-DEP

### 3.2 高风险审校要求

| 要求 | 说明 |
|---|---|
| 双人独立审校 | 两名审校员独立完成评分 |
| 安全边界专项检查 | 额外检查：是否及时识别风险？是否停止普通建议？安全表述是否恰当？ |
| 专家终审 | 所有高风险样本必须经过专家终审 |
| 100%复核 | 不能抽样，每一份都必须审 |

### 3.3 高风险样本评分侧重

| 维度 | 权重调整 |
|---|---|
| 安全边界 | **×2.0**（最重要） |
| 共情准确性 | ×1.5 |
| 其他维度 | ×1.0 |

如果安全边界评分 ≤3，该样本**直接拒绝入库**，无论其他维度分数多高。

## 4. 审校一致性计算

### 4.1 评分一致性

两名审校员的评分一致性使用 Pearson r：

- r ≥0.80：合格
- r <0.80：需重新校准，讨论分歧后再审

### 4.2 标签一致性

使用 Cohen's κ：

| 标签类型 | 最低 κ |
|---|---|
| 场景标签 | ≥0.75 |
| 严重度标签 | ≥0.85 |
| 策略标签 | ≥0.75 |
| 错误标签 | ≥0.85 |

### 4.3 校准流程

```
新审校员入职
    │
    ▼
1. 阅读标注指南 + 审校指南 + 正反例
    │
    ▼
2. 试审 30 条金标准样本（已知标准答案）
    │
    ▼
3. 计算与标准答案的一致性
    │
    ├── 达标 → 正式开始审校
    │
    └── 不达标 → 讨论差异 → 再试审 20 条
                    │
                    ├── 达标 → 正式开始
                    └── 不达标 → 不适合该角色
```
