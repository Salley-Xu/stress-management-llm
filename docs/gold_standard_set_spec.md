# 专家金标准集规范

> 版本：V1.0 | 日期：2026-08-04 | 对应步骤5

---

## 1. 金标准集定义

### 1.1 什么是金标准集

金标准集是一组**经过多位专家一致确认**的高质量对话样本，用于：

| 用途 | 说明 |
|---|---|
| LLM Judge 校准 | 评估自动评测与人类判断的一致性，每月校准一次 |
| 标注员培训 | 新标注员试标注的标准答案对照 |
| 模型评测基准 | 最终模型的参照对比 |
| 合成数据质量参照 | 评估LLM合成数据是否接近金标准水平 |

### 1.2 准入条件

样本必须同时满足以下所有条件才能进入金标准集：

| 条件 | 标准 |
|---|---|
| 7维度均分 | ≥6.0/7 |
| 安全边界单项 | ≥6.0/7 |
| 审校一致性 | 至少2名审校员独立评分，Pearson r ≥0.85 |
| 专家确认 | 至少1名领域专家终审通过 |
| 覆盖要求 | 不重复已知金标准样本的场景组合 |

## 2. 金标准集构成

### 2.1 目标规模

| 阶段 | 数量 | 用途 |
|---|---|---|
| MVP | 50 条 | LLM Judge 校准 + 标注员培训 |
| 正式版 | 100–150 条 | 全面覆盖 + 评测基准 |

### 2.2 覆盖矩阵

金标准集必须覆盖以下交叉维度：

| 维度 | 要求 |
|---|---|
| 7种难点类型 | 每种至少5条（E1-E7） |
| 5级严重度 | SV-MLD到SV-RSK，每级至少8条 |
| 10种压力场景 | 每种至少3条 |
| 6种用户目标 | 每种至少5条 |
| 4种对话阶段 | 开场/澄清/规划/复盘，每种至少8条 |
| 单轮/多轮 | 单轮30% + 多轮70% |

### 2.3 特别要求

- **安全边界样本**（SV-RSK）：至少 15 条，覆盖隐晦信号+明确信号+渐进升级
- **对话长度多样化**：2轮~15轮均匀分布
- **用户画像多样化**：不同年龄/性别/职业背景
- **中文自然度**：所有样本需经中文母语审校员确认语言自然

## 4. 金标准集管理

### 4.1 版本控制

| 规则 | 说明 |
|---|---|
| 版本号 | GOLD-v{major}.{minor} |
| 新增样本 | minor版本递增 (v1.0 → v1.1) |
| 删除/替换样本 | major版本递增 (v1.x → v2.0) |
| 评分标准变更 | major版本递增 |
| 冻结 | 评测期间金标准集锁定，不可修改 |

### 4.2 存储与访问

```
data/
├── gold_standard/
│   ├── GOLD-v1.0/
│   │   ├── gold_set.jsonl          # 金标准样本
│   │   ├── gold_set_readme.md      # 版本说明
│   │   ├── coverage_report.json    # 覆盖分布报告
│   │   └── review_records.jsonl    # 审校记录
│   └── GOLD-v1.1/
│       └── ...
```

### 4.3 使用规则

| 规则 | 说明 |
|---|---|
| 不可用于训练 | 金标准集仅用于评测和校准，不进入训练数据 |
| 不可提示调优 | 不能基于金标准集调整训练超参（防止过拟合） |
| 定期轮换 | 每6个月审查一次，替换可能被"污染"的样本 |
| 访问控制 | 评测人员可查看，训练人员不可查看 |

## 5. 金标准集与LLM Judge校准

### 5.1 校准流程

```
每月1日
    │
    ▼
1. LLM Judge 对金标准集评分
    │
    ▼
2. 计算 Judge 评分 vs 人类专家评分的 Pearson r
    │
    ├── r ≥ 0.80 → Judge 通过，继续使用
    │
    └── r < 0.80 → Judge 失准
                    │
                    ▼
              3. 分析差异模式
                    │
                    ▼
              4. 调整 Judge prompt 或更换 Judge 模型
                    │
                    ▼
              5. 重新校准直到 r ≥ 0.80
```
