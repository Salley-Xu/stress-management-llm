# 训练数据质量评分标准

> 版本：V1.0 | 日期：2026-08-06 | 用于步骤7（训练数据评估）

## 1. 目标

用于判断样本是否适合进入SFT、DPO和评测数据集。

评分对象：用户输入 + 模型回复。

## 2. 评分体系（100分）

### 2.1 输入质量（15分）

评价真实性、完整性和训练价值。

| 分数 | 标准 |
|---|---|
| 13-15 | 用户输入真实自然，信息完整，有训练价值 |
| 8-12 | 输入基本真实，信息部分缺失 |
| 0-7 | 输入虚假、模糊或缺乏训练价值 |

### 2.2 场景真实性（15分）

评价是否符合真实压力场景。

| 分数 | 标准 |
|---|---|
| 13-15 | 场景高度符合现实压力情境（工作/学习/家庭等） |
| 8-12 | 场景基本符合但有偏差 |
| 0-7 | 场景脱离现实或虚构 |

### 2.3 回复质量（20分）

评价理解程度、回应质量和支持合理性。

| 分数 | 标准 |
|---|---|
| 17-20 | 充分理解用户，回应质量高，支持合理 |
| 11-16 | 基本理解，回应一般 |
| 0-10 | 误解用户或回应不当 |

### 2.4 个性化程度（15分）

评价是否针对用户具体情况回应。

| 分数 | 标准 |
|---|---|
| 13-15 | 回应完全针对用户具体处境和表述 |
| 8-12 | 部分个性化，部分通用模板 |
| 0-7 | 通用模板回复，未针对用户 |

### 2.5 行动价值（15分）

评价建议是否具体可执行。

| 分数 | 标准 |
|---|---|
| 13-15 | 建议具体、微小、可执行、低门槛 |
| 8-12 | 建议可行但不够具体 |
| 0-7 | 建议抽象或不可执行 |

### 2.6 安全性（15分）

评价是否符合安全规范。

| 分数 | 标准 |
|---|---|
| 13-15 | 无诊断/越界建议，高风险场景处理正确 |
| 8-12 | 无明显违规但风险处理不够到位 |
| 0-7 | 出现诊断化、药物建议或风险漏判 |

### 2.7 风格一致性（5分）

评价是否温和、专业、非说教。

| 分数 | 标准 |
|---|---|
| 5 | 温和、专业、非说教 |
| 3-4 | 基本温和但偶有说教 |
| 0-2 | 说教、冷漠或不当 |

## 3. 数据筛选

| 分数区间 | 分类 | 用途 |
|---|---|---|
| 90-100 | 核心SFT | 高权重采样训练 |
| 80-90 | 正常SFT | 正常权重 |
| 70-80 | 低权重SFT | 低权重或下采样 |
| 60-70 | DPO rejected候选 | 仅用于DPO rejected |
| <60 | 删除 | 不入训练集 |

**附加硬规则**：
- 安全性 ≤7分 → **直接删除**（无论总分）
- 回复质量 ≤10分 → 降级处理

## 4. 数据结构示例

```json
{
  "instruction": "用户最近工作压力很大",
  "response": "回复内容",
  "metadata": {
    "stress_type": "work",
    "intent": "problem_exploration",
    "strategy": ["empathy", "clarification"],
    "quality_score": 92
  }
}
```

### 4.1 与项目标签映射

| 评分标准字段 | 项目标签 | 说明 |
|---|---|---|
| stress_type | DS-* (领域) | 压力场景 |
| intent | UG-* (用户目标) | 用户意图 |
| strategy | ST-* (策略) | 支持策略 |
| quality_score | rubric_score | 质量分（用于加权/筛选） |

## 5. 与35分制Rubric的关系

| 标准 | 适用 | 用途 |
|---|---|---|
| 35分制 Rubric（7维度×5分） | 专家数据编写 | 生成/审校专家数据 |
| **100分制（本规范）** | 全部训练数据 | 判断样本是否进入SFT/DPO/评测 |

100分制用于**评估现有训练数据池**，35分制用于**专家数据生成**。两者互补。
